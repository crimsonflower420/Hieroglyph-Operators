深さの在りかWhere the depth sits

同じ語について、配置の木（層 A）と機能の木（層 B）の高さを測り、漢字の字の中の木の高さと並べる。漢字では深さが字の内側にあり、ヒエログリフでは語の記号のあいだ、方形をまたいだところにある（HYPOTHESIS。第3節）。これは置き場所の違いであって、優劣ではない。For the same words, the height of the layout tree (layer A) is measured against the height of the function tree (layer B), and set beside the height of the tree inside a kanji. In kanji the depth sits inside the character; in hieroglyphs it sits between the signs of a word, across quadrats (HYPOTHESIS; section 3). This is a difference in where the depth is placed, not a ranking.

1. 測り方1. How it is measured

高さは、根から葉までの一本の道の上にある、項数2以上の演算子の節点の最大数である。項数1の節点（層 A の CARTOUCHE、層 B の ABBR、KanjiVG の一枠だけの入れ物）は数えない。三つの資料に同じ規則を当てる。Height is the largest number of operator nodes of arity 2 or more on one path from the root to a leaf. Arity-1 nodes (CARTOUCHE in layer A, ABBR in layer B, one-slot wrapper groups in KanjiVG) are not counted. The same rule is applied to all three sources.

  • hQ：語の中でいちばん高い方形一つの高さ（方形の中の深さ）。hQ: the height of the tallest single quadrat in the word (depth inside a quadrat).
  • hA：層 A 全体の高さ。記号が二つ以上の方形に分かれるときは、方形を並べる LINE の一段が hQ に加わる。hA: the height of all of layer A. When the signs are spread over two or more quadrats, the LINE step that sets the quadrats in a row adds one to hQ.
  • hB：層 B（記号のはたらき）の高さ。hB: the height of layer B (sign function).
  • hBx / hBin：層 B の一本の道の上で、葉が二つ以上の方形にまたがる節点の最大数（hBx、方形をまたぐ深さ）と、葉が一つの方形に収まる節点の最大数（hBin、方形の中の深さ）。hBx / hBin: on one path of layer B, the largest number of nodes whose leaves lie in two or more quadrats (hBx, depth across quadrats), and the largest number whose leaves lie inside one quadrat (hBin, depth inside a quadrat).

資料は三つ。（1）ラフマン再読の26件の導出（記法 v1。どの木も HYPOTHESIS）。層 B が OPEN の d25 を除く25件を使う。（2）大英博物館 EA 581（インテフの石碑）の方形調査（Nederhof の HieroJax 符号化。パイロット調査）。（3）常用漢字2,136字の木（KanjiVG 70a0b7ae、「順序の漢字」の組み立ての規則）。計算は tools/kanji_heights.py と tools/depth_compare.py、結果は data/depth-compare.json にある。漢字側の計算は、項数調査の数（組み立て6,176、入れ子の深さ最大7）を再現できなければ止まる。Three sources. (1) The 26 derivations of the Rahman re-read (notation v1; every tree HYPOTHESIS); the 25 with a layer B are used, leaving out d25, whose layer B is OPEN. (2) The quadrat census of British Museum EA 581, the stela of Intef (Nederhof's HieroJax encoding; see Pilot). (3) The trees of the 2,136 jōyō kanji (KanjiVG 70a0b7ae, with the composition rule of Kanji in Order). The scripts are tools/kanji_heights.py and tools/depth_compare.py; the results are in data/depth-compare.json. The kanji script stops unless it reproduces the arity census totals (6,176 compositions, deepest group depth 7).

ラフマンの導出：同じ語で層 A と層 B を比べるRahman derivations: layer A against layer B for the same words

方形の中の高さ hQ は平均0.60で、2に届くのは1件（d22）だけである。層 B の高さ hB は平均2.08、最大4（d15, d20）。25件のうち hB が hQ より高いのが21件、等しいのが4件で、低いものはない。層 A 全体（hA、平均1.44）と比べても、hB が高いのが13件、等しいのが12件、低いのは0件である（例はラフマンの本により、頁は各導出に記す。数はこのリポジトリで数えた）。Height inside a quadrat, hQ, averages 0.60; only 1 derivation reaches 2 (d22). Layer B height, hB, averages 2.08, with a maximum of 4 (d15, d20). Of the 25, hB is greater than hQ in 21, equal in 4, and smaller in none. Against all of layer A (hA, mean 1.44), hB is greater in 13, equal in 12 and smaller in 0 (examples from Rahman's book, page per derivation; counts computed in this repository).

層 B の深さがどこにあるかを見ると、方形をまたぐ段数 hBx は平均1.68、方形の中の段数 hBin は平均0.44である。25件のうち18件で hBx が hBin を上回り、4件で等しく、3件（d08, d22, d24）で逆になる。逆の3件は、どれも記号がただ一つの方形に収まる例である（一方形の例は4件：d08, d22, d23, d24）。As to where layer B's depth sits: the number of steps across quadrats, hBx, averages 1.68, and the number inside a quadrat, hBin, averages 0.44. In 18 of the 25 hBx exceeds hBin, in 4 they are equal, and in 3 (d08, d22, d24) it is the other way round. Those 3 are all cases whose signs fit in a single quadrat (the single-quadrat cases are 4: d08, d22, d23, d24).

名や句（GEN・NAME・PHRASE・COORD・ATTR を含むもの：d19, d20, d21, d22, d24）を除いた語だけの20件でも形は同じである。hQ 平均0.50、hB 平均2.00、hB が hQ より高いのは20件中18件。d03 の層 B は、2026年11月27日に限定符で閉じる木に決めた（未決の解決）。このため hB は以前の補音の木の1から2になった。増えた段は方形をまたぐ段である。Keeping only the 20 single words (leaving out names and phrases, i.e. trees with GEN, NAME, PHRASE, COORD or ATTR: d19, d20, d21, d22, d24) gives the same shape: hQ mean 0.50, hB mean 2.00, hB above hQ in 18 of 20. For d03, layer B was decided on 27 Nov 2026 as the tree closed by a determinative (Resolutions), so hB is now 2 instead of 1 for the earlier complement tree; the added step is across quadrats.

インテフの石碑（EA 581）：配置だけIntef stela (EA 581): layout only

石碑全体の294グループ（一記号だけのもの65を含む）で、方形の高さは平均1.03、最大3。2以上は64（22%）である（Nederhof の符号化、このサイトの調査）。この石碑については、語の区切りも記号のはたらきの注記もまだリポジトリにないので、層 B の高さは OPEN である。Over the stela's 294 groups (including 65 lone signs), quadrat height averages 1.03, with a maximum of 3; 64 (22%) reach 2 or more (Nederhof's encoding; this site's census). For this stela the repository has no word segmentation and no sign-function annotation yet, so its layer-B height is OPEN.

漢字：字の中の木Kanji: the tree inside the character

常用2,136字の字の中の木は平均2.49で、2以上が1,830字（86%）、最大6（棄、滞、旗、縫）である（KanjiVG 70a0b7ae、「順序の漢字」の規則）。高さ0、つまり組み立てのない字は58字。漢字側の数は配置（部品の組み立て）の木だけで、意符・音符の機能の木はこの比較にはない（OPEN）。したがって漢字の数と並べるべきなのは hQ と hA であり、hB ではない。The tree inside a jōyō kanji averages 2.49; 1,830 characters (86%) reach 2 or more, and the maximum is 6 (棄, 滞, 旗, 縫) (KanjiVG 70a0b7ae, Kanji in Order's rule). 58 characters have height 0, that is, no composition. The kanji number is a layout tree (how components are put together) only; there is no semantic/phonetic function tree for kanji in this comparison (OPEN). So the kanji number should be set against hQ and hA, not against hB.

3. 読み3. Reading

HYPOTHESIS. 漢字の配置の深さは字の内側にある（平均2.49）。ヒエログリフの配置の深さは方形の中では浅く（EA 581 で平均1.03、ラフマンの例で0.60）、同じ語の機能の深さ（平均2.08）の多くは方形をまたいだところで組まれる（hBx 1.68 対 hBin 0.44）。深さは消えたのではなく、置き場所が違う。HYPOTHESIS. Kanji layout depth sits inside the character (mean 2.49). Hieroglyphic layout depth is shallow inside a quadrat (mean 1.03 on EA 581, 0.60 in the Rahman cases), while most of the function depth of the same words (mean 2.08) is built across quadrats (hBx 1.68 against hBin 0.44). The depth has not gone missing; it sits somewhere else.

限界。Limits.

  • ラフマンの例は本が説明のために選んだもので、無作為の標本ではない。件数も25と少ない。Rahman's examples were chosen by the book to make teaching points; they are not a random sample, and there are only 25.
  • 層 B の高さは記法 v1 の決め方に左右される（たとえば CMPL は多子音記号と補音を一つの節点で閉じ、INFL や PL は一段ずつ積む）。別の記法なら数は変わりうる。Layer-B height depends on choices in notation v1 (for example, CMPL closes a multiliteral and its complements in one node, while INFL and PL stack one step at a time). Another notation could give other numbers.
  • 漢字の高さは KanjiVG の入れ子の付け方に左右される。単位も違う。漢字の木は一字の中の部品の組み立てで、方形の木は語をまたぎうる配置の単位である。Kanji heights depend on how KanjiVG nests its groups. The units also differ: a kanji tree is the composition of components inside one character, while a quadrat tree is a layout unit that may cut across words.
  • 高さは木の形の数であり、読みやすさや書く人の頭の中の手順については何も言わない。Height is a number about tree shape; it says nothing about legibility or about any procedure in the writer's mind.
並行関係（グラントの承認待ち）。漢字では配置の深さが集まる単位が「字」であり、ここで測ったヒエログリフの例では機能の深さが集まる単位が「語」（いくつかの方形の列）である、と書ける。どちらも文字の層についての記述であり、統語の主張ではない。Parallel (for Grant to approve). One could write it this way: in kanji the unit that collects layout depth is the character, while in the hieroglyphic cases measured here the unit that collects function depth is the word (a row of several quadrats). Both describe the writing layer; neither is a syntactic claim.

未決の問いOpen questions

  • OPEN：EA 581 の語ごとの層 B。TLA の語の区切りと方形の符号化の突き合わせはできた（方形の境目と語の境目）。層 B はまだ書いていない。OPEN: layer B word by word for EA 581. The TLA word division is now aligned with the quadrat encoding (Quadrat and word boundaries); layer B is not yet written.
  • OPEN：漢字の機能の木（意符・音符）の高さ。KanjiVG の部首や音符の属性から木を作れるかは未確認。OPEN: the height of a kanji function tree (semantic and phonetic components). Whether one can be built from KanjiVG's radical and phonetic attributes is not yet checked.
