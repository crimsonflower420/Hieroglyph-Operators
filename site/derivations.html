記法 v1 によるWritten in notation v1

二層の導出Two-layer derivations

記号の組み合わせを、二つの木で書く。層 A は紙面の配置（方形）であり、層 B は記号のはたらき（表音・補音・限定符・語尾）である。二つの層は同じ葉 n1, n2 … を共有し、葉の番号でつながる。A sign combination is written as two trees. Layer A is the layout on the surface (the quadrat); layer B is what the signs do (phonogram, complement, determinative, ending). Both layers share the same leaves n1, n2 … and are linked by those ids.

書式は記法 v1にしたがう。角括弧の形（ブラケット形式）が正本であり、このサイトの図はすべて tools/derivations.py がそこから生成する。データは data/derivations/rahman.drv にある。The format follows notation v1. The bracket form is the source of truth, and every figure on this site is generated from it by tools/derivations.py. The data are in data/derivations/rahman.drv.

1. 層 A：配置1. Layer A: layout

層 A は幾何だけを書く。主要部はない。演算子は Unicode の書式制御文字にほぼ一対一で対応する。方形の中の左右 ⿰ と、方形を並べた列 LINEk は区別する。前者は横の結合 U+13431 で、後者は結合子なしの並びである。Layer A records geometry only and has no heads. Its operators map almost one-to-one onto the Unicode format controls. Side by side inside a quadrat (⿰) is kept apart from a row of quadrats (LINEk): the first is the horizontal joiner U+13431, the second is plain juxtaposition.

2. 層 B：型付きの機能2. Layer B: typed function

層 B の演算子は型をもつ。たとえば CMPL は「多子音記号＋補音 → PHON」、CLOSE は「WORD＋限定符 → WORD_closed」である。主要部は層 B にだけ現れ、限定符の葉に _H を付けて示す。Layer B operators are typed: CMPL is 'multiliteral + complement → PHON', CLOSE is 'WORD + determinative → WORD_closed'. Heads appear only in layer B, marked _H on the determinative leaf.

3. 例：nfrt「美しい（女）」3. Example: nfrt 'beautiful (woman)'

d10 · nfrt「美しい（女）」：配置の列と機能のまとまりが交差するnfrt 'beautiful (woman)': a layout column that cuts across the function grouping

HYPOTHESIS · 本書book p. 42–43 · n1=F35 n2=I9 n3=D21 n4=X1 n5=B1

層 A：配置（主要部なし）Layer A: layout (headless)
[LINE3 n1 [⿳ n2 n3 n4] n5]
層 B：型付きの機能（主要部 _H）Layer B: typed function (heads _H)
[CLOSE [INFL2 [CMPL3 n1:PHON3 n2:COMPL n3:COMPL] n4:FEM] n5:DET_H]

WALK_write = WALK_read = n1 n2 n3 n4 n5

MISMATCH (B) · CMPL3 {n1, n2, n3} — 配置のどの構成素とも一致しないcoincides with no layout constituent

本書Book本書は Loy を引き、nfrt に女の限定符を加えると「美しい女」になると述べる。同じ nfrt に冠や牝牛の記号を付けた例も Kinnaer から挙げる（pp. 42–43）。Citing Loy, the book says adding the woman determinative to nfrt gives 'beautiful woman', and cites Kinnaer for the same nfrt with a crown or a cow (pp. 42–43).

標準StandardI9（f）と D21（r）は nfr の補音、X1 は女性語尾 -t、B1 は限定符である（Gardiner 1957、記号表 F35・B1）。I9 (f) and D21 (r) complement nfr, X1 is the feminine ending -t, B1 is a determinative (Gardiner 1957, sign list F35, B1).

注Note図では f・r・t が一つの縦の列［⿳］に積まれる。機能の層では f・r は nfr とまとまり、t は語尾として外に出る。配置の構成素と機能の構成素は一致しない（検査器が MISMATCH を出す）。限定符を替えると語の部類が替わる、という本書の観察は、層 B の主要部の入れ替えとして書ける。In the figure f, r and t sit in one vertical column [⿳]. In the function layer f and r go with nfr, while t stands outside as the ending. The layout constituent and the function constituent do not coincide (the checker reports MISMATCH). The book's point that changing the determinative changes the word's class can be written as swapping the head in layer B.

出典Refs: Gardiner 1957

この例では、配置の列［⿳ f r t］が機能のまとまりと交差する。検査器は、層 B の節点のうち、葉の集合が層 A のどの節点とも、またどの節点の連続した娘の並びとも一致しないものを MISMATCH として報告する。Here the layout column [⿳ f r t] cuts across the function grouping. The checker reports a layer-B node as MISMATCH when its leaf set equals no layer-A node and no contiguous run of one layer-A node's daughters.

4. 順序：木と歩き4. Order: trees and walks

木は階層だけを表す。順序は木の上の線形化として別に書く。WALK_write は層 A の葉を左から、縦の結合では上から辿った並びである。本書（pp. 60–61）が Bruaw から引く「上の記号が先」という規則は、この既定の歩きの定義そのものである（d25）。WALK_read は読む順で、層 B の葉の並びと一致しなければならない。A tree records hierarchy only; order is written separately as linearizations over it. WALK_write is the leaf order of layer A read left to right, top first at vertical joins. The rule the book takes from Bruaw (pp. 60–61), signs above come first, is exactly the definition of this default walk (d25). WALK_read is the reading order and must equal the leaf order of layer B.

二つの歩きが食い違うときは、木は一つのまま、歩きの上に並べ替えを記す（規格の既定 (b)）。ラベルは TRANSPOSE(honorific) または TRANSPOSE(graphic) である。漢字のサイトの「書き順と歩き順の置換」の語彙でいえば、敬意による転置は reorder の型に当たる。尊ぶ語のかたまりが、それが追い越すかたまりより先に書かれる。今回の例には return の型に当たるものはない。When the two walks differ, the tree stays single and the reorder is marked on the walk (the standard's default (b)), labelled TRANSPOSE(honorific) or TRANSPOSE(graphic). In the vocabulary of the kanji site's written order vs walk order, honorific transposition is of the reorder type: the honoured block is written ahead of the block it passes. No case of the return type occurs here.

並行関係（グラントの承認待ち）。漢字の reorder（書き順で部品のかたまりが先に出る）と、ヒエログリフの敬意による転置（尊ぶ語が先に書かれる）は、どちらも「一つの木、二つの歩き、かたまり一つの入れ替え」という同じ形で書ける。どちらも文字の層の話であり、統語の主張ではない。Parallel (for Grant to approve). The kanji reorder (a component block comes earlier in stroke order) and hieroglyphic honorific transposition (the honoured word is written first) can both be written in the same shape: one tree, two walks, one block swapped. Both are about the writing layer; neither is a syntactic claim.

Peust（2007）は、敬意による転置が話し言葉の統語上の倒置規則によく似ていると論じる。このサイトはその見方を紹介するにとどめ、移動 (a) は使わない。規格は、層 B がそれを支持するときにだけ移動を許している。Peust (2007) argues that honorific transposition closely mimics syntactic inversion rules of spoken languages. This site reports that view but does not use movement (a); the standard allows movement only when layer B argues for it.

5. 検査5. Checks

python3 tools/derivations.py は次を確かめ、一つでも外れれば失敗する。演算子の項数。両層がすべての葉をちょうど一度ずつ使うこと。層 A に役割や主要部がないこと。主要部が限定符だけにあり、限定符はかならず主要部であること。CMPL の娘が多子音記号一つと補音から成ること。CLOSE が限定符で終わること。層 B の葉の並びが WALK_read と等しいこと。歩きが食い違うときに限って並べ替えのラベルがあること。どの木にも HYPOTHESIS が付いていること。python3 tools/derivations.py checks the following and fails on any breach: operator arity; both layers use every leaf exactly once; no roles or heads in layer A; heads only on determinatives, and every determinative a head; CMPL daughters are one multiliteral plus complements; CLOSE ends in a determinative; layer B's leaf order equals WALK_read; a reorder label is present exactly when the walks differ; every tree carries HYPOTHESIS.

主張しないことWhat is not claimed

記号の木は統語ではなく、Merge・X バー・θ役割の主張でもない。書き順や読み順は心理的な導出の主張ではない。層 B は語の形態や意味の木そのものではなく、二つの層が同じものだとも主張しない。Glyph trees are not syntax, and make no claim about Merge, X-bar or θ-roles. Writing or reading order is not claimed as a psychological derivation. Layer B is not word morphology or semantics as such, and the two layers are not claimed to be the same thing.
